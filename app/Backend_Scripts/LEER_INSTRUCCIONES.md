# Scripts del Backend (Google Apps Script)

Esta carpeta contiene el código fuente de los scripts que hacen funcionar la Base de Datos en Google Sheets.

## Historial de Versiones:
* **`01_Script_Google_Completo.gs`**: Versión actual en producción. Incluye registro estricto, asistencia virtual/presencial, progreso de unidades y preparado para recibir calificaciones de exámenes.

## ¿Cómo actualizar el servidor?
Si en el futuro creamos un script `02_...`, solo debes:
1. Abrir tu archivo de Google Sheets.
2. Ir a **Extensiones > Apps Script**.
3. Reemplazar el código por el archivo nuevo.
4. Clic en **Implementar > Administrar implementaciones > Editar (lápiz) > Nueva versión > Implementar**.
