UNIDAD 3

Unidad III: Fundamentos de Administración de Bases de Datos

Resumen Temático

Archivos convencionales. Definición de base de datos. Ventajas en el uso de base de datos. El manejo del sistema de base de datos (DBMS). El administrador de la base de datos (DBA). Tipos de modelos de base de datos. Bases de datos distribuidas. Data warehouse.

1. Archivos convencionales

Conjuntos de registros gestionados por cada aplicación, sin integración centralizada y con acceso secuencial o indexado.

Limitaciones: redundancia, inconsistencia, dificultad de acceso, seguridad limitada y falta de integridad automática.

2. Definición de base de datos

Conjunto de datos relacionados y organizados para facilitar acceso, gestión y actualización.

Elementos: datos, metadatos, tablas/registros/campos y relaciones.

4. DBMS: manejo del sistema de base de datos

Funciones: definición (DDL), manipulación (DML), control de acceso, transacciones ACID, optimización de consultas, y respaldo/recuperación.

Componentes: DDL, DML, motor de almacenamiento, gestor de transacciones y catálogo de metadatos.

Ejemplos: MySQL, PostgreSQL, Oracle, SQL Server, MongoDB y servicios en la nube.

5. El administrador de la base de datos (DBA)

Funciones: diseño e implementación, seguridad, respaldo y recuperación, optimización, monitoreo, mantenimiento, gestión de usuarios, documentación y planes de contingencia.

Tipos: de sistemas, de desarrollo, de aplicaciones y arquitecto de datos.

6. Modelos, distribución y data warehouse

Modelos: jerárquico, de red, relacional (tablas + SQL), orientado a objetos, documental, multidimensional, deductivo y transaccional.

Distribuidas: datos en múltiples nodos con transparencia, autonomía y replicación; ganan disponibilidad y escalabilidad, con desafíos de consistencia, complejidad y costo.

Data warehouse: repositorio integrado, histórico y no volátil para análisis (ETL + BI); a diferencia de la BD transaccional (OLTP), se optimiza para lectura (OLAP).
