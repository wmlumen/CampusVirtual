Unidad VII: Tecnologías de Apoyo a la Toma de Decisiones

Resumen Temático

Plataforma de sistemas transaccionales. El proceso de toma de decisiones. Definición y tipos de sistemas de apoyo a las decisiones. Características de los sistemas de apoyo para la toma de decisiones (DSS). Caso de aplicación de un DSS. Sistemas de apoyo para la toma de decisiones en grupo (GDSS). Características de los GDSS. Ventajas y desventajas del uso de GDSS. Diseño de salas. Usos prácticos de un GDSS. Casos de aplicación. Inteligencia artificial. Sistemas expertos. Beneficios que genera el uso de sistemas expertos y costos que involucra. El generador de sistemas expertos o Shell. Selección de aplicaciones para sistemas expertos.

1. De registrar datos a decidir

Los TPS registran operaciones (ventas, facturas, pagos, inventarios). Miles de operaciones acumuladas permiten analizar productos, clientes, horarios y tendencias.

Cadena de valor: transacciones → datos → BD → análisis → información → alternativas → decisión → acción.

La tecnología mejora la información de quien decide; no siempre decide por sí misma.

2. Proceso y tipos de decisión

Etapas: identificación del problema, recolección de información, análisis, generación y evaluación de alternativas, selección, implementación y evaluación de resultados.

Tipos de decisión:

  • Estructuradas: automatizables (ej.: reposición por mínimo).
  • Semiestructuradas: datos + juicio (ej.: cuánto comprar).
  • No estructuradas: ej.: ingresar a un nuevo mercado.
3. DSS: apoyo a la decisión

DSS (Decision Support System): integra datos, modelos, software e interfaz para el decisor.

Herramientas: análisis what-if (¿qué pasaría si...?), sensibilidad y escenarios (optimista/probable/pesimista).

Caso: elegir sucursal comparando población, alquiler, competencia y ventas, simulando variaciones antes de invertir.

Un DSS apoya, no sustituye automáticamente al gerente.

4. GDSS: decisiones en grupo

GDSS: facilita decisiones colectivas (documentos, propuestas, votación, comparación, colaboración a distancia).

Ventajas: más alternativas, registro y estructuración.

Desventajas: resistencia, conflictos, dependencia y costos.

Salas: computadoras, pantalla, conectividad y software colaborativo (hoy también virtuales).

Usos: planificación, presupuestos, proveedores, proyectos y riesgos.

5. Inteligencia artificial y sistemas expertos

IA: reconocimiento, clasificación, predicción y recomendaciones (demanda, fraude, clientes).

Sistema experto: base de conocimiento + motor de inferencia + interfaz; ej.: SI liquidez baja Y endeudamiento alto ENTONCES riesgo elevado.

Beneficios: conserva conocimiento, consistencia y apoyo a no expertos.

Costos: adquisición, validación, actualización y mantenimiento.

Shell: entorno para construirlos sin partir de cero.

Selección: conocimiento identificable, reglas claras, problema repetitivo y valor económico.

Evolución: TPS → MIS → DSS → GDSS → IA.
