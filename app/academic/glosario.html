Glosario de Términos TIC

Diccionario interactivo de acrónimos y siglas técnicas - Redes, WiFi y Dispositivos

Acrónimo Inglés Español ¿Qué es?
AP Access Point Punto de Acceso Dispositivo que crea una red WiFi y permite que dispositivos se conecten a la red cableada.
API Application Programming Interface Interfaz de Programación de Aplicaciones Conjunto de reglas que permite que dos aplicaciones se comuniquen entre sí.
CASE Computer Aided Software Engineering Ingeniería de Software Asistida por Computadora Herramientas de software utilizadas para automatizar y apoyar las distintas fases del ciclo de vida del desarrollo de sistemas.
CPU Central Processing Unit Unidad Central de Procesamiento El "cerebro" de la computadora. Hardware encargado de interpretar y ejecutar instrucciones y procesar datos.
CRM Customer Relationship Management Gestión de Relaciones con Clientes Estrategia y software utilizado para administrar y analizar las interacciones de una empresa con sus clientes.
DFD Data Flow Diagram Diagrama de Flujo de Datos Representación gráfica que muestra cómo se mueve la información a través de un sistema o proceso empresarial.
DSS Decision Support System Sistema de Apoyo a la Toma de Decisiones Sistema de información gerencial interactivo que ayuda a los directivos a tomar decisiones analizando escenarios semiestructurados.
EIS Executive Information System Sistema de Información Ejecutiva Herramienta para la alta dirección que consolida métricas clave e información estratégica en paneles o tableros de control.
ER Entity-Relationship Entidad-Relación Modelo conceptual que ilustra cómo las entidades (personas, objetos, conceptos) se relacionan entre sí en una base de datos.
ERP Enterprise Resource Planning Planificación de Recursos Empresariales Software de gestión integral que unifica finanzas, RRHH, manufactura y ventas en una base de datos centralizada.
HDD Hard Disk Drive Unidad de Disco Duro Dispositivo de almacenamiento magnético tradicional utilizado para guardar información de forma permanente.
IT / TI Information Technology Tecnología de la Información Uso de computadoras, redes y almacenamiento para procesar y gestionar datos electrónicos en organizaciones.
LMS Learning Management System Sistema de Gestión de Aprendizaje Plataforma de software (como Moodle) utilizada para administrar, distribuir y evaluar educación virtual (e-learning).
MIS Management Information System Sistema de Información Gerencial Sistema enfocado en procesar datos operativos para generar informes estandarizados para gerentes de nivel medio.
RAM Random Access Memory Memoria de Acceso Aleatorio Memoria principal temporal de la computadora, extremadamente rápida pero volátil (se borra al apagar el equipo).
SaaS Software as a Service Software como Servicio Modelo en la nube donde una empresa aloja un software y el cliente lo utiliza a través de internet pagando una suscripción.
SI Information System Sistema de Información Conjunto interrelacionado de hardware, software, personas y datos que procesa información para alcanzar un objetivo.
SSD Solid State Drive Unidad de Estado Sólido Dispositivo moderno de almacenamiento sin partes móviles, significativamente más rápido y resistente que un HDD tradicional.
TPS Transaction Processing System Sistema de Procesamiento de Transacciones Sistemas operativos básicos que registran las operaciones rutinarias del día a día (ej. cajero de supermercado).
TQM Total Quality Management Aseguramiento de la Calidad Total Enfoque de gestión integral que busca la mejora continua y la excelencia en todas las fases de un producto o servicio.
LANLocal Area NetworkRed de Área LocalRed que conecta dispositivos en un área pequeña como casa, oficina o aula.
WANWide Area NetworkRed de Área AmpliaRed que cubre grandes distancias, como Internet que conecta ciudades y países.
WLANWireless LANRed Inalámbrica LocalLAN sin cables, usando WiFi para conectar dispositivos.
WiFiWireless FidelityFidelidad InalámbricaTecnología que permite conexión a internet sin cables mediante ondas de radio.
SSIDService Set IdentifierIdentificador de RedNombre que identifica tu red WiFi (ej. "Centuria_Alumnos").
RouterRouterEnrutadorDispositivo que dirige el tráfico entre tu red local e Internet.
SwitchSwitchConmutadorConecta varios dispositivos cableados dentro de una LAN.
DNSDomain Name SystemSistema de Nombres de DominioTraduce nombres (google.com) a direcciones IP.
DHCPDynamic Host Configuration ProtocolProtocolo de Configuración DinámicaAsigna automáticamente direcciones IP a los dispositivos.
IPInternet ProtocolProtocolo de InternetDirección única de cada dispositivo en la red (ej. 192.168.1.10).
TCP/IPTransmission Control Protocol / Internet ProtocolConjunto de Protocolos de InternetBase de la comunicación en Internet.
HTTP/HTTPSHyperText Transfer Protocol (Secure)Protocolo WebHTTP es web sin cifrar, HTTPS es versión segura con candado.
VPNVirtual Private NetworkRed Privada VirtualTúnel seguro para acceder a la red desde fuera.
IoTInternet of ThingsInternet de las CosasObjetos cotidianos conectados (focos, aires, sensores) que envían datos por internet.
BluetoothBluetoothBluetoothConexión inalámbrica de corto alcance para audio y datos.
NFCNear Field CommunicationComunicación de Campo CercanoConexión por contacto (pagos con celular).
USBUniversal Serial BusBus Universal en SeriePuerto estándar para conectar pendrives, celulares y periféricos.
GPUGraphics Processing UnitUnidad de Procesamiento GráficoChip para gráficos y video, clave para juegos e IA.
URLUniform Resource LocatorLocalizador de RecursoDirección web completa (ej. https://centuria.edu.py).
4G/5GFourth/Fifth GenerationRed Móvil 4ª/5ª Gen.Tecnologías móviles; 5G es 10x más rápida que 4G.
