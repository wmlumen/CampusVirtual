        <h4 class="mb-3 mt-4" style="color:#C5A55A; border-bottom:2px solid #E6F4EA; padding-bottom:10px;">
         Desarrollo de contenidos
        </h4>
        <h5 class="mt-4 mb-2" style="color:#007A33;">
         1. Definiciones y conceptos
        </h5>
        <p>
         <strong>
          Sistema de Información (SI):
         </strong>
         conjunto de componentes interrelacionados que recolectan, procesan, almacenan y distribuyen información para apoyar la toma de decisiones, la coordinación, el control y el análisis en una organización.
        </p>
        <p>
         <strong>
          Sistema de Información Computarizado:
         </strong>
         SI que utiliza hardware, software, redes y bases de datos para procesar y almacenar información de manera eficiente.
        </p>
        <p>
         <strong>
          Tecnología de la Información (TI):
         </strong>
         herramientas y recursos tecnológicos (computadoras, servidores, redes, software) que permiten el tratamiento automatizado de la información.
        </p>
        <p>
         <strong>
          Dato vs. información:
         </strong>
         el dato es el registro bruto (ej.: G. 4.500.000); la información es el dato procesado y contextualizado (ej.: las ventas de agosto crecieron 8 % respecto de julio).
        </p>
        <h5 class="mt-4 mb-2" style="color:#007A33;">
         2. Clasificación de los sistemas de información
        </h5>
        <p>
         <strong>
          A. Sistemas de apoyo a las operaciones:
         </strong>
         sistemas de procesamiento de transacciones (TPS), que registran las operaciones diarias; sistemas de control de procesos, que monitorean procesos físicos o industriales; y sistemas de colaboración empresarial, que facilitan la comunicación y el trabajo en equipo.
        </p>
        <p>
         <strong>
          B. Sistemas de apoyo administrativo y gerencial:
         </strong>
         sistemas de información gerencial (MIS), que generan informes para la gestión; sistemas de apoyo a la toma de decisiones (DSS), para decisiones semiestructuradas; y sistemas de información ejecutiva (EIS), con información estratégica para la alta dirección.
        </p>
        <h5 class="mt-4 mb-2" style="color:#007A33;">

        <h5 class="mt-4 mb-2" style="color:#007A33;">
         4. Las tecnologías de la información y la sociedad
        </h5>
        <p>
         <strong>
          Impactos positivos:
         </strong>
         acceso a la información, automatización, eficiencia y conectividad global.
         <strong>
          Desafíos:
         </strong>
         brecha digital, privacidad, seguridad y dependencia tecnológica.
        </p>
        <h5 class="mt-4 mb-2" style="color:#007A33;">
         5. Desarrollo y ciclo de vida de los sistemas
        </h5>
        <p>
         El desarrollo comprende: identificación de necesidades, análisis de requerimientos, diseño, implementación y pruebas, puesta en producción y mantenimiento. El
         <strong>
          ciclo de vida
         </strong>
         recorre: planificación, análisis, diseño, implementación, pruebas, instalación y uso/mantenimiento.
        </p>
        <p>
         <strong>
          Variables determinantes:
         </strong>
         calidad (cumplimiento de especificaciones), recursos (personal, presupuesto, tiempo), complejidad técnica y riesgos (tecnológicos, organizacionales o de mercado).
        </p>
        <h5 class="mt-4 mb-2" style="color:#007A33;">
         6. Métodos de adquisición
        </h5>
        <p>
         <strong>
          Método tradicional:
         </strong>
         desarrollo interno, control total pero mayor tiempo y costo.
         <strong>
          Compra de paquetes:
         </strong>
         software comercial (ej.: ERP), rápida implementación con posible necesidad de adaptación.
         <strong>
          Outsourcing:
         </strong>
         contratación de terceros, acceso a expertise con riesgo de dependencia.
         <strong>
          Desarrollo por el usuario final:
         </strong>
         macros y planillas, rápido pero con riesgo de falta de estándares.
         <strong>
          CASE:
         </strong>
         herramientas de software que apoyan el modelado, la generación de código, las pruebas y la documentación.
        </p>
        <h5 class="mt-4 mb-2" style="color:#007A33;">
         7. Calidad, diseño, pruebas y mantenimiento
        </h5>
        <p>
         <strong>
          Aseguramiento de la calidad total:
         </strong>
         revisiones, pruebas, auditorías y mejora continua (normas ISO 9001 e ISO/IEC 25000).
         <strong>
          DFD:
         </strong>
         entidades externas, procesos, flujos y almacenes de datos;
         <strong>
          ER:
         </strong>
         modelado de bases de datos; más manuales y diccionarios de datos.
         <strong>
          Pruebas:
         </strong>
         unitarias, de integración, de sistema y de aceptación.
         <strong>
          Mantenimiento:
         </strong>
         correctivo, preventivo, adaptativo y perfectivo.
        </p>

        async function cargarRolesDisponibles(){
            const cedula=sessionStorage.getItem('current_cedula');
            if(!cedula) return;
            try{
                if(window.CenturiaAPI && CenturiaAPI.getRoles){
                    const r=await CenturiaAPI.getRoles(cedula);
                    const roles=(r&&r.roles)||[];
                    if(roles.length){ sessionStorage.setItem('roles',JSON.stringify(roles)); renderizarRolesDisponibles(roles); return; }
                }
                const stored=JSON.parse(sessionStorage.getItem('roles')||'[]');
                if(stored.length) renderizarRolesDisponibles(stored);
            }catch(e){console.error('Error cargando roles:',e);}
        }

        function actualizarProgresoInline(leidos, total) {
            if (leidos === undefined) {
                const textoEl = document.getElementById('progreso-texto');
                if (textoEl) {
                    const match = textoEl.textContent.match(/(\d+)\s*\/\s*(\d+)/);
                    if (match) { leidos = parseInt(match[1]); total = parseInt(match[2]); }
                }
                if (leidos === undefined) { leidos = 0; total = 1; }
            }
            const pct = total > 0 ? Math.round((leidos / total) * 100) : 0;
            const elTexto = document.getElementById('progreso-texto-inline');
            const elBar = document.getElementById('progreso-bar-inline');
            const elPct = document.getElementById('progreso-pct-inline');
            if (elTexto) elTexto.textContent = leidos + '/' + total;
            if (elBar) elBar.style.width = pct + '%';
            if (elPct) elPct.textContent = pct + '%';
        }
